# RelayIR benchmark report

## Setup

This v0.3 report contains the corrected official matrix: 384 redacted records from
12 official fixtures × four contracts. There are eight evaluation and four holdout
fixtures, six English and six Spanish fixtures, and three fixtures per role across
the four roles. DeepSeek and Sol use n=3 per fixture/contract; Luna and Terra use
n=1. The four models are kept in separate groups.

## Method

Each run used a fresh, closed-book OpenCode session with the same fixture facts and
one contract: free prose v1, Cavecrew v1, the deployed OpenCode H1 profile v2, or
JSON v1. The H1 arm is aligned with `contracts/opencode-h1-v1.md`, the explicit
profile deployed by the npm plugin. Fidelity is literal preservation of fixture
facts, constraints, evidence, and next action; it is not coding correctness.
Totals are provider-reported input, output, reasoning, and cache token categories,
not estimates. Failures and missing usage remain in the matrix and affect the
displayed success and token metrics.

Regenerate the aggregate tables from the committed redacted evidence with:

```bash
npm run benchmark:report -- benchmarks/results/2026-08-19-v03.jsonl
```

No model run is required to inspect the evidence or reproduce its aggregate tables.
The compact JSONL intentionally excludes prompts, responses, and timestamps.

## Result / interpretation

All model/split/contract groups have median fidelity 1. H1 does not beat free prose
or Cavecrew on score/token in the DeepSeek or Sol holdout; H1 total tokens are
generally higher, so this evidence supports no superiority claim. DeepSeek H1 has
one missing-final-text failure in evaluation, plus one missing-final-text failure
and one content-preservation failure in holdout, represented by success 0.9583 and
0.8333. The GPT groups have success 1 with the corrected contract. These are
descriptive summaries only; no p-values or generalization claims are made.

## Limitations

DeepSeek and Sol provide three repetitions, while Luna and Terra are exploratory
n=1 groups. The fixture set is small and closed-book: this measures preservation of
authoritative handoff content, not open-ended coding correctness, agent quality, or
production performance. Provider-reported totals include input, output, reasoning,
and cache usage; absent usage is visible rather than imputed. The historical legacy
`+37%` n=1 smoke result is not the v0.3 headline. The first v0.3 attempt used a
legacy H1 prompt and is not public evidence; this report uses the deployed profile.
