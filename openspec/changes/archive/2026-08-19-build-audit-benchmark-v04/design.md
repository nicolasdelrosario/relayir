# Design

The existing agentic runner is extended rather than replaced. It materializes deterministic synthetic fixtures, invokes one task-only parent, injects a contract only into the child, exports root and child sessions, and writes one redacted row per planned attempt. Fixture task prompts state only the substantive analysis, implementation, or architecture job and do not request handoff fields; only checklist, JSON, or H1 child injection requests handoff contents. Task input uses the actual `prompt` field when present; delegated-prompt equality is an independent diagnostic and never prevents child export or usage collection. `none` is a true injection no-op; `h1` is a descriptive historical control and cannot reopen H1/H2.

The locked plan is 8 tasks × 4 contracts × 2 parents × 3 repeats = 192 attempts (96 per parent), with contracts rotated by trial within each task. Each row independently records child and parent outcome, evidence, constraint, format, and non-contradiction checks, hierarchy/delegation checks, artifact validity, provider usage, contract/fixture versions, elapsed latency, and named failure diagnostics. JSON uses v2 repository-inspection rules. No judge calls, retries, raw outputs, nonces, prompts, transcripts, absolute paths, or timestamps are persisted. A pre-freeze calibration permits a child to mention a fixture decoy when it is not a competing allowed outcome; source references remain strict and fixture-relative. A spike is exactly the first fixture, checklist, one repeat, and one row.

The gate first requires a complete 192-row matrix (96 per parent, 24 per contract, eight tasks, three trials), then checks instrumentation (at least 95% hierarchy-valid, exact-delegation, and complete root/child usage rows per parent), then the none hidden-handoff defect rate (at least 20% for each parent). `PILOT_CHECKLIST` additionally requires checklist evidence-plus-constraint transfer to improve by at least 20 percentage points per parent, parent outcome to fall by no more than 5 percentage points per parent, and known median all-run token overhead no greater than 10% per parent. Passing only the auditor prerequisite yields `AUDIT_ONLY`; failing it yields `MAINTENANCE_ONLY`. JSON and H1 are descriptive controls only. Artifact metrics use only non-null artifact rows.
