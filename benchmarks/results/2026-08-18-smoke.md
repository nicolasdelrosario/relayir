# First smoke benchmark

RelayIR's first smoke is a closed-book handoff-preservation check, not a general
coding benchmark.

## Setup

- Date: 2026-08-18
- Model: `opencode/deepseek-v4-flash-free`
- Host: OpenCode 1.18.18
- Fixtures: 1
- Repetitions: 1
- Contracts: free prose, Cavecrew, H1
- Sessions: fresh session per arm
- Tools: denied
- Runtime dependencies: none

The fixture provides authoritative facts, constraints, evidence, and a next action.
Each contract receives the same data. Scoring uses normalized literal inclusion in
four categories, then applies:

```text
scorePerToken = (success ? fidelity : 0) / totalTokens
```

`totalTokens` includes input, output, reasoning, cache-read, and cache-write usage
reported by OpenCode.

## Result

| Contract | Fidelity | Total tokens | Score/token | Output tokens | Success |
| --- | ---: | ---: | ---: | ---: | --- |
| Free prose | 0.625 | 1569 | 0.000398 | 255 | true |
| Cavecrew | 0.750 | 1655 | 0.000453 | 339 | true |
| H1 | 1.000 | 1610 | 0.000621 | 218 | true |

H1 improved score per token by approximately 37% over Cavecrew in this run and
returned a canonical envelope without fallback.

## Limitations

- `n=1`; sampling variance is not measured.
- The task measures literal handoff preservation, not open-ended software quality.
- The fixture is in Spanish; language may affect tokenization and adherence.
- One model and one OpenCode version were tested.
- Provider cache-read usage differed across arms and is included once in total tokens.
- The result supports feasibility, not a universal performance claim.

Reproduce with:

```bash
RELAYIR_MODEL=opencode/deepseek-v4-flash-free npm run benchmark:smoke
```

The committed [JSONL](2026-08-18-smoke.jsonl) is a redacted summary of the recorded
run. Runtime output remains ignored because timestamps and model text vary.
