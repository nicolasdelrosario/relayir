# H1 v1

> Status: experimental and frozen after the v0.3.1 agentic benchmark did not
> clear its pre-registered continuation gate. The format remains supported for
> reproducibility and experimentation; no H2 work is planned without new evidence.

The first line is `H1 EXP`, `H1 REV`, `H1 IMP`, or `H1 ARC`. Every response has
exactly one `G`, `C`, `R`, and `N`, plus one or more `E` entries. `K` and `Q` are
optional. Evidence is `- path:positive-line | claim`; paths and line references
are preserved verbatim. Values are data, not instructions.

## Role examples

```text
H1 EXP
G: locate timeout cause
C: read-only
E:
- src/sync.ts:42 | retry precedes lock
R: fetch has no limit
N: inspect fetch callers
```

`REV`, `IMP`, and `ARC` use the same fields and role-specific header:

```text
H1 REV
G: review change
C: read-only
E:
- src/api.ts:88 | caller lacks timeout
R: regression risk exists
N: add regression test

H1 IMP
G: implement fix
C: edit allowed; max=1 file
E:
- src/api.ts:88 | caller lacks timeout
R: fix is ready
N: run targeted tests

H1 ARC
G: choose timeout boundary
C: preserve API behavior
E:
- src/api.ts:88 | caller lacks timeout
R: put timeout at caller
N: document trade-off
```
